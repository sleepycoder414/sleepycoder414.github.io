# Empty-shell furnishing revision

This revision supersedes the original furnished-reference edit plan. The five current files in `ref/` are empty architectural renders. Existing moodboards, palettes, examples and guides are retained. Missing base assets from the interrupted run are completed; existing ones are not regenerated.

Every style receives five newly furnished condo concepts. Style examples supply furniture silhouettes, upholstery, lighting, rugs and decoration. They do not supply room architecture. The furnished living-wide result supplies a common furniture reference for alternate views. Exact prompts and input roles are in each folder's `prompt.json`; `status.json` tracks generation and visual review.

The earlier guides remain useful style descriptions. For this revision, references to keeping existing furniture, six dining chairs, seven views or two bedrooms are superseded: design from the empty shell, use four indoor dining chairs, and cover only the five current views. A queen bed, two nightstands and two lamps furnish the primary bedroom. The solarium receives outdoor dining and lounge furniture. Architecture and the saved Blender model are not being redesigned.

Review compares each furnished concept with its style examples, checks required furniture and looks for camera/shell drift and consistency across the three shared-room views. These image concepts are not measured Blender furniture placements; minor generative differences remain possible.
