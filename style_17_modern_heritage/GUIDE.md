# Modern Heritage / New Traditional

Familiar traditional patterns and vintage character edited for a modern apartment.

**Fit for this condo: Good.** Start with a patterned rug and framed art, keeping large furniture simple.

## Main elements

- Materials: walnut; small-scale botanical cloth; wool; ceramic; aged brass.
- Shared living and dining: olive tailored sofa; round walnut coffee table; walnut media cabinet; walnut rectangular table with six cream upholstered chairs; pleated linen pendants.
- Bedrooms: oak queen beds, ivory quilt, muted burgundy throws, vintage botanical prints.
- Solarium: teak chairs with olive cushions and table.
